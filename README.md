# Jardin de Saison

Site du primeur et de l'épicerie asiatique Jardin de Saison, 98 rue Saint-Charles, Paris 15ᵉ.

Site statique (HTML, CSS, JavaScript, sans dépendance) : ouvrir `index.html` pour le consulter en local.
Chaque push sur `main` le publie sur GitHub Pages.

- `index.html` : accueil, étals, calendrier des saisons, rayon Asie, avis, services, commande, boutique
- `panier.html` : panier, coordonnées et envoi de la commande par WhatsApp ou e-mail
- `js/shop.js` : produits, prix, panier et **coordonnées de la boutique** (téléphone, WhatsApp, e-mail) à renseigner en haut du fichier
